# v3.1.0: unslopovich is now unslop-anything

Same doctor, new name. It matches the other projects by the same author, [rust-anything](https://github.com/erkamyaman/rust-anything) and [safe-anything](https://github.com/erkamyaman/safe-anything). Dr. Unslopovich still runs the clinic.

## What changes for you

- Install with `npx unslop-anything` and call it with `/unslop-anything review my app` (`$unslop-anything` in Codex).
- The Claude Code plugin is `/plugin marketplace add erkamyaman/unslop-anything`, then `/plugin install unslop-anything@unslop-anything`.
- The npm package `unslopovich` is deprecated and points here.

## What keeps working

- `unslopovich-ignore` comments are still honored next to the new `unslop-anything-ignore`.
- `.unslopovich/config.json` and `.unslopovich/chart.md` are still read when the new `.unslop-anything/` folder is missing. The next `chart` moves them.
- `npx unslop-anything` removes a skill folder named `unslopovich` that an older version installed, so your agent doesn't load both.
- Old GitHub links redirect to the new repository.
